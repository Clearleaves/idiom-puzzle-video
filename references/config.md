# 每期配置

JSON 用 UTF-8 编码。脚本支持以下字段；字段遗漏时使用默认值。

| 字段 | 类型与限制 | 用途 |
|---|---|---|
| idiom | 必填，4 个汉字 | 答案 |
| clues | 必填，4 个非空字符串 | 揭晓时按顺序显示，以加号连接 |
| explanation | 必填，非空字符串 | 谐音或取字解释 |
| episode | 整数 1–999，默认 1 | 栏目期数 |
| title | 默认“看图猜成语” | 主标题 |
| subtitle | 默认“四个线索，你能连起来吗？” | 副标题 |
| hint | 默认“提示：试试谐音” | 中途提示 |
| closing | 默认“你答对了吗？明天再猜一道” | 片尾文案 |
| guess_seconds | 整数 5–25，默认 11 | 猜题时间 |
| answer_seconds | 整数 3–10，默认 5 | 揭晓时间 |
| filename | 无扩展名的安全文件名，默认使用 idiom | 输出文件名前缀 |

脚本会缩小较长文字以适应宽度，但仍需人工检查；提示和解释尽量简短。脚本固定 1080×1920、24 fps，其他规格需要明确修改渲染器。

两个可复制起点：
- [五谷丰登](../assets/wugufengdeng.json)：五＋谷＋枫＋灯。
- [十全十美](../assets/shiquanshimei.json)：十＋犬＋十＋梅；提示小狗也叫犬。

输出：`<filename>.mp4`、`<filename>_封面.jpg`、`<filename>_检查.json`。检查报告包含画幅、计划时长、帧数、音频峰值、解码结果；不代表人工已审阅。
